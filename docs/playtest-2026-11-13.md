# Interactive playtest — 13 November 2026

Played through the visible in-app browser, starting at 0/6 on an isolated localhost origin. The existing user origin and its saved passport were preserved.

## Verified by playing

- Apollo 17: incomplete assembly fails with a material hint; a revised taped-and-clamped 60 cm, 0°, 8 cm design passes its fictional dust and wheel-clearance checks. Stamp earned.
- Surveyor 3: repeated measurements at the same force count as one distinct force; two deliberately selected forces and three scoops provide evidence. A narrow footprint sinks; a wider footprint succeeds. Switching away and back can be retested successfully. Stamp earned.
- Curiosity: Step moves the rover; Undo restores its start position. A ten-block route using repeat commands reaches the outcrop and uplink. The unsupported life claim is rejected; the habitability report earns its stamp.
- Ingenuity: rotor additions and discharge produce the expected 65% setting. A paced, stable flight to the crater rim fails at touchdown. A flat-ground retry succeeds and earns its stamp. Four credentials do not trigger graduation.
- Webb: both wings open using actual pointer drags. Star A drags into focus; B and C align with the direction controls. Infrared reveals the illustration and earns the fifth stamp.
- Voyager: reading the original greeting and saving a written Vietnamese greeting earns the sixth stamp without microphone permission.
- Automatic finale opens at 6/6. Both finale and certificate contain exactly six stamp elements. Empty-name certificate validation works; Escape closes the celebration and returns focus to the certificate button.
- At a 390px viewport the lobby, Moon panel and Webb controls remain readable without document overflow. The temporary viewport was reset after testing.

## Problems found and fixed

1. Surveyor's success event only fired once, so switching sites after a successful unclaimed trial could permanently hide the completion ceremony. Every valid retest now re-offers completion; persistent credential ownership still prevents duplicate stamps.
2. The probe silently changed its selected force after each measurement. It now keeps the learner's chosen force, matching the instructions and allowing controlled comparisons.
3. Replacing a Moon ceremony removed the focused button and left keyboard focus on the document. Focus now moves to the final-transmission heading.
4. Clearing or undoing the final rover command disabled the focused control. Focus now returns to the command palette.
5. The global button hover rule made Webb's star transparent while keeping dark text. Dedicated hover styles preserve the bright star and mirror-wing surfaces.
6. Ingenuity's first incorrect controller selection displayed only the character's encouragement, hiding the explanation of signal delay. It now displays both the character line and the actionable explanation, using separate localizable text nodes.
7. Missing/stale DSN data used the same message as confirmed absence of Voyager contact. It now explicitly reports unavailable data, with Spanish and Vietnamese translations. Fresh valid feeds retain the existing contact behavior.

## Limits

The local build has no configured Horizons mission API, so its live-distance panel correctly reports an unavailable anchor. Real current Horizons distance was not verified in this playtest. Actual microphone capture and physical printing were not exercised; written-greeting completion, certificate contents and validation were checked.

Validation: `npm test` — 105 passing; production build succeeds. A controller regression test covers Surveyor force retention and recovery after changing patches. Existing DSN tests now distinguish missing/stale data from a fresh feed with no active signal. No deployment performed.
